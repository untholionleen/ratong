Current system direction

基础框架先稳定，题库后结构化。

真题模块暂不塞入未经整理的数据；后续采用“考试 → 套卷 → Section → Passage → Question → Option → Answer → Explanation → Audio”链路导入。

Data governance

公开可学，发布需审。

访客可读取“已审核词书”；词书上传进入待审核队列；只有管理员能发布、撤回、改名和删除。学生学习记录只允许本人读取。

Import specification

推荐词书字段

必填：单词 word
建议：美音标、英音标、词性、词义
进阶：英文解释、例句、例句翻译、难度、标签
音频：可提供 us_audio_url / uk_audio_url；没有时由浏览器 TTS 兜底

当前词书信息

本地示范
公开词书必须先经过管理员审核。上传本身不会直接发布。

推荐导入方式

  1. 一个 Excel 文件只放一本词书。
  2. 首行作为字段名；不要合并单元格。
  3. 单词一行一条；字段缺失可留空。
  4. 上传后进入“待审核”，管理员发布后所有访客即可加载。
